Google Sheet Sync

Connect to a Google Sheet so the dashboard works across devices and survives browser resets. Status changes write to the sheet in real time; the dashboard polls every 8 seconds for incoming changes.

Not connected.
How to set this up (one-time, ~5 minutes)
  1. Create a new Google Sheet. Name it anything (e.g., DismissFlow Live).
  2. In the sheet, go to Extensions → Apps Script. A code editor opens.
  3. Delete any starter code, paste the entire Apps Script below, and click the save icon.
  4. Click Deploy → New deployment. Choose type Web app.
  5. Set Execute as: Me, Who has access: Anyone. Click Deploy.
  6. Authorize when prompted. Copy the resulting Web app URL (ends in /exec).
  7. Paste it in the field above and click Connect.
  8. On first connect, click Push current to sheet to seed the sheet with the 18 bus/group rows.
